# VENATOR LAB 2.0

Минималистичный персональный трекер матчей Venator в Deadlock. Статический сайт без npm, сервера и внешних библиотек.

## Возможности
- Один Dashboard: победы, души/мин, KDA, смерти/10 мин, динамика фарма.
- Подробный ввод матчей с необязательными таймингами 3/10/15/20 минут, урнами, разломами, мид-боссом и использованием способности.
- Одна тренировочная цель на 5 **новых** матчей, сравнение по выбранному числовому показателю.
- Сохранение в localStorage, резервное копирование JSON, импорт JSON, экспорт CSV.
- Адаптивный дизайн для компьютера и телефона.

## Публикация на GitHub Pages

1. Распакуйте архив. Загрузите **содержимое** папки `venator-lab-2` в корень репозитория GitHub. Если обновляете прежний проект, удалите старые `src`, `public`, `dist`, `package*.json`, `vite.config.ts` и старый `index.html` замените новым. Не смешивайте старый Vite-проект и новый статический сайт.
2. Убедитесь, что в корне есть `index.html`, `app.js`, `styles.css`, а workflow лежит в `.github/workflows/pages.yml`.
3. Settings → Pages → Source → **GitHub Actions**.
4. В Actions проверьте успешное выполнение `Publish VENATOR LAB 2.0`.
5. Сайт: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

**Рекомендуется:** сначала создать отдельный репозиторий `venator-lab-2`, чтобы старый рабочий сайт остался доступным до проверки нового.

## Данные и ограничения
- Данные хранятся **только в текущем браузере на текущем адресе сайта**. Они не синхронизируются через GitHub. Перед очисткой браузера или сменой адреса скачайте JSON-резервную копию.
- Старые данные VENATOR PERFORMANCE LAB v1 автоматически **не импортируются**: структура отличается. Новый импорт принимает только резервные копии v2.
- Процент изменений рассчитывается по средним выбранных последних N матчей относительно предшествующих N (если они есть). Малые выборки нестабильны.
- Для цели учитываются пять новых матчей после её создания. Отсутствующий показатель не считается успехом.
- Использование способности вводится вручную. Простой и «упущенные применения» намеренно не вычисляются без достоверного лога доступности/перезарядок — только теоретическая оценка была бы вводящей в заблуждение.
- Все введённые значения — пользовательские, статистика не подключается к игровому API.

## Запуск локально
Откройте `index.html` в браузере. Для полного тестирования можно использовать любой локальный HTTP-сервер, но для GitHub Pages ничего устанавливать не требуется.
